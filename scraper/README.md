# Скрапер телеграм-каналов

Прототип. Читает публичные телеграм-каналы с программами, разбирает посты в
структурированные карточки через Gemini и отправляет их в заявки ExchangeHub
на модерацию. Ничего не публикует напрямую в каталог.

## Как это работает

1. `fetch_posts()` забирает посты через веб-превью `https://t.me/s/<channel>` —
   без api_id, входа по номеру и прав админа в канале. Минус: только публичные
   каналы и неглубокая история.
2. Грубый фильтр по ключевым словам (`KEYWORDS`) отсекает мемы и анонсы, чтобы
   не тратить на них квоту модели.
3. Gemini разбирает текст по строгой JSON-схеме (`SCHEMA`). В промпт передаётся
   дата публикации поста — без неё не развернуть «до 15 марта» в дату.
4. Программы, проходящие внутри России, отсеиваются: поле `is_in_russia` плюс
   регулярка `RU_PLACES` как страховка. Критерий — где человек окажется
   физически, а не прописка организатора.
5. Годное уходит в `POST /api/submissions` с припиской `Automatically added`
   в конце описания.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

В корневой `.env` проекта нужны:

```
GEMINI_API_KEY=...            # aistudio.google.com/apikey
SCRAPER_EMAIL=...             # аккаунт, от имени которого создаются заявки
SCRAPER_PASSWORD=...
```

## Запуск

```bash
# посмотреть, что соберётся, не трогая модель и сайт
.venv/bin/python tg_scraper.py beyondsd --no-llm

# разобрать, но никуда не отправлять
.venv/bin/python tg_scraper.py beyondsd --limit 5

# каналы из channels.txt, с отправкой в заявки
.venv/bin/python tg_scraper.py --limit 5 --submit
```

Каналы берутся из аргументов (через пробел) или, если их нет, из `channels.txt`.

| Флаг | Что делает |
|---|---|
| `--submit` | отправлять в заявки; без него — только показ |
| `--limit N` | сколько постов отдать модели на каждый канал |
| `--pages N` | сколько страниц истории пролистать (по 16–20 постов) |
| `--model` | модель Gemini; для тестов `gemini-flash-lite-latest` |
| `--keep-russia` | не отсеивать программы внутри России |
| `--api` | базовый URL сайта, по умолчанию прод |
| `--no-llm` | только собрать посты |

## Дедуп

Отправленные посты запоминаются в `seen.json` по каналам и при следующих
прогонах пропускаются **до** обращения к модели. На бэкенде проверки на повтор
нет, так что без этого файла каждый прогон плодил бы дубли заявок. Начать
с чистого листа — удалить `seen.json`.

## Квота Gemini

Бесплатный тариф — порядка 20 запросов в сутки на основную модель, один пост
разбирается 20–25 секунд. При исчерпании суточного лимита скрипт печатает
сообщение и останавливается, сохранив уже разобранное. Свои лимиты видно
в https://aistudio.google.com/rate-limit.

## Что ещё не сделано

- Нет поля «источник» в заявке — пока происхождение видно только по приписке
  `Automatically added` в описании.
- Нет дедупа по ссылке на программу: одну стажировку постят несколько каналов.
- Запуск руками; cron не настроен.
- В `SYSTEM` стоит добавить 2–3 реальных примера постов с готовым JSON —
  это поднимает точность сильнее, чем правки формулировок.
